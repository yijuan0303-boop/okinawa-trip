JAPAN ENTRY · 2026
2026 日本入境注意事項
以 2026/09/15 查到的官方資料整理；出發前仍建議再確認一次
① 台灣護照短期觀光
持有台灣身分證統一編號的普通護照，赴日短期觀光原則上可免簽，每次最長 90 天。請備妥回程機票、住宿、行程與足夠旅費等資料，以備入境查驗。（資料：外交部領事事務局）
② Visit Japan Web
入境前可使用 Visit Japan Web 登錄入境與海關資料；日本海關目前建議電子申報。每位旅客原則上都要完成自己的資料，QR Code 可先截圖備用。（資料：日本海關／Visit Japan Web）
③ COVID-19
日本厚生勞動省目前公告：入境日本不需要疫苗證明或出發前 COVID-19 檢測，也沒有一般入境後隔離要求。（資料：日本厚生勞動省）
④ 食品／藥品不要亂帶
日本對肉製品、植物、水果蔬菜、藥品等有禁止或限制規定；不要因為「台灣買得到」就直接放進行李。入境前請逐項確認。（資料：日本海關）
⑤ 現金／高價物品
攜帶現金、旅行支票或有價證券等合計達 100 萬日圓以上，或符合規定的黃金達一定門檻時，需申報；海關也有旅客免稅額度規定。（資料：外交部領事事務局）
⑥ 最後檢查
護照、虎航機票、住宿訂單、Visit Japan Web、旅平險、信用卡／現金、手機網路，建議全部存在手機離線資料夾。
官方入口：Visit Japan Web／日本海關／日本厚生勞動省／外交部領事事務局。各國入境規定可能變動，出發前請以官方最新公告為準。（官方資料）
